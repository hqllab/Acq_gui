# 曝光相关命令

## 预备（仅需设置一次）

- 允许球管A曝光(bit0) `allow_exposure 1`

## 设置（根据需要，设置后持续有效）

- 球管A电压110 `set_voltage 0 110`
- 球管A电流10 `set_current 0 10`
- 球管A曝光时间（时间固定为9000ms） `set_max_exposure_time 0 9000`

## 运动（根据需要，设置后持续有效）

- 移动到1100.0mm，速度200.0mm/s `move 11000 2000`
- 持续移动到1100.0mm，速度200.0mm/s `continuous_move 11000 2000`
    - 与固定移动的差别是，移动中按enter可以中断移动
- 设置曝光终点（曝光后将从当前位置移动到设置位置）`set_exposure_pos 13000 400`
    - 当前在1100mm，设置1300mm，按下手闸后将自动从1100mm跑到1300mm
- 查询当前位置 `state`
    - 其中的'pos': [18500, 0]是当前的位置和速度
    - 其中的'cap': [9, 0]是两个球管的热容量

## 曝光（每次执行）

- 进入曝光模式（进入后可以根据提示按手闸） `enter_exposure_mode`
    - 提示"曝光模式——准备未完成"后可以按预备手闸
    - 提示"曝光模式——准备完成"后可以按曝光手闸
    - 每次曝光完要再次进入才能曝光，不在状态中按手闸无效
    
exit_exposure_mode
